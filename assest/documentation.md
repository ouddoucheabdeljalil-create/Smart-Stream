1. AXIOS :
=> Axios est une bibliothèque JavaScript qui permet d’effectuer des requêtes HTTP pour communiquer avec une API et récupérer ou envoyer des données
2. fetch :
=>Fetch est une fonction JavaScript qui permet d’envoyer des requêtes HTTP et de récupérer des données depuis une API.
3. XMLHttpRequest (XHR):
=> XMLHttpRequest est un objet JavaScript qui permet d'envoyer des requêtes HTTP et de recevoir des données depuis un serveur, notamment dans le cadre d'AJAX.
4. Synchrone :
=> le code s'exécute ligne par ligne, chaque ligne attend la précédente.
6. Asynchrone :
=> une opération longue démarre sans bloquer le reste du code. On attend son résultat avec await.
7. MockAPI :
=>site qui crée une fausse API de test à partir de nos données. Ici, la ressource channel renvoie la liste des chaînes.
8. AJAX (Asynchronous JavaScript and XML):
=>AJAX est une technique JavaScript qui permet d'échanger des données avec un serveur sans recharger toute la page web.
9. JSON :
=> Format simple pour stocker et échanger des données.
10. BSON:
=> Format binaire utilisé pour stocker des données.
11. YAML : 
=> Format qui organise les données avec des espaces.
12. XML :
=> Format qui organise les données avec des balises.
